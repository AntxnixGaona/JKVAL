02 / Lectura

Cómo se usa el rango

El rango acota la muestra. Nunca se mezcla un rango con «todos» sin decirlo, y una división con pocos datos no se presenta como conclusión.

Divisiones

Ocho niveles tienen tres divisiones cada uno (I, II y III); Radiante es una sola insignia. La página de combinaciones permite consultar cada división por separado.

Ver combinaciones por división

Muestra

Las cifras de esta página cuentan partidas, no jugadores. Un mismo jugador puede aparecer en varias. La distribución es sintética y está fijada por una semilla reproducible.
