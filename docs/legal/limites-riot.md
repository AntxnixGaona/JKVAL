# Límites de uso de propiedad intelectual de Riot Games

Fecha de revisión: 2026-10-28.
Fuente consultada: `https://www.riotgames.com/en/legal` («Legal Jibber Jabber», actualizado en agosto de 2018).

## 1. Qué dice la política (verificado)

- Riot concede una licencia **personal, no exclusiva, no sublicenciable, no transferible, revocable y limitada** para usar su propiedad intelectual en **proyectos de fans gratuitos y no comerciales**.
- Riot puede **cancelar o bloquear** cualquier proyecto en cualquier momento.
- **No se pueden usar logos ni marcas registradas de Riot** sin un acuerdo escrito: ni en el proyecto, ni en web, publicidad, vídeo u otra publicación; tampoco registrar dominios o cuentas con sus marcas.
- Si el proyecto se comparte, debe incluir de forma visible: «*[título] was created under Riot Games' “Legal Jibber Jabber” policy using assets owned by Riot Games. Riot Games does not endorse or sponsor this project.*»

## 2. Cómo se aplica a JKVAL

| Elemento | Estado | Decisión |
|---|---|---|
| Nombre «JKVAL» y logotipo | Original del proyecto | No usa la marca de Riot |
| Nombre «VALORANT», agentes y mapas | Marcas de Riot | Uso descriptivo en contexto educativo local; **no** se usan como marca del producto |
| Arte, retratos, renders, emblemas e iconos | Propiedad de Riot | Solo uso local educativo; **no publicados** hasta confirmar permiso |
| Tipografías oficiales (Tungsten-Bold, DIN Next) | Propietarias | **No** se usan; se sustituyen por OFL |
| Estadísticas | Sintéticas propias | No proceden de Riot ni de terceros |
| Logos de Riot | Prohibidos sin acuerdo | **No** se incorporan |

## 3. Consecuencias operativas

1. El proyecto se mantiene **local y no publicado**. Preparar el despliegue no equivale a publicarlo.
2. Antes de publicar hay que obtener permiso escrito para los assets y revisar el uso de marcas; mientras no exista, la copia pública no es viable.
3. La página `/aviso-legal/` incluye la no afiliación y el aviso de la política. Si el proyecto se comparte, ese aviso debe permanecer visible.
4. No se acepta monetización, publicidad, donaciones con contraprestación ni venta de acceso.
5. No se usan APIs privadas, extracción de Tracker.gg ni datos personales de jugadores.
6. Si Riot solicita el cese, se retira el contenido y los assets afectados.
